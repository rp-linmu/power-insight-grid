# 当前开发成果

本轮已经完成项目的一期工程骨架开发，重点包括：

## 1. 后端

- 建立了 `FastAPI` 项目结构
- 建立了 `SQLite` 初始化脚本与基础数据表
- 建立了 Excel `xlsx` 标准库解析能力
- 建立了导入逻辑：
  - 时序数据导入
  - 明细表导入
  - 文本类披露导入
  - 政策文件元数据登记
- 建立了日期校验规则：
  - 校验外部文件名日期
  - 校验 sheet 名日期
  - 若存在表内业务日期，以表内日期为准
  - 若没有表内业务日期，则按 sheet 日期

## 2. 前端

- 建立了首页看板
- 建立了信息披露页
- 建立了政策文件页
- 建立了预测模块页
- 建立了统一视觉风格和响应式布局

## 3. 下一步建议

最合理的后续开发顺序是：

1. 把前端改成调用后端真实接口
2. 补充导入管理页面
3. 补充 PDF 文本提取与摘要
4. 接入真实预测结果
5. 再补登录权限和后台管理
