# 数据与材料准备清单

为了把项目真正做起来，建议你提供以下材料。

## 1. 信息披露模块所需材料

- 你已有的披露数据样例文件
  - 最好提供 3 到 5 份真实或脱敏 Excel
- 每类指标的字段说明
  - 例如统调负荷、地方电源出力、A类电源出力、新能源出力
- 每类数据的时间粒度
  - 24 点、96 点，或两者都有
- 每类数据的单位
  - MW、MWh、元/MWh 等
- 数据更新频率
  - 每日一次、日内多次等
- 数据来源
  - 网页手工整理、Excel、接口抓取、内部系统导出

## 2. 结构化文本数据材料

- Excel 样例文件
- 列字段说明
- 哪些字段必须保留
- 是否需要全文检索

## 3. 政策文件模块所需材料

- 政策文件样例
  - PDF、Word、网页文本均可
- 期望的分类方式
  - 按区域、机构、主题、业务条线
- 你希望摘要输出的格式
  - 例如“摘要、核心条款、影响分析、适用对象”
- 是否允许调用外部 AI 接口进行摘要

## 4. 预测模块所需材料

- 当前已有的预测结果样例
  - 如果已有模型，提供结果文件即可
- 如果没有模型，至少提供历史训练数据
  - 电价
  - 负荷
  - 新能源出力
  - 天气
  - 节假日
  - 机组检修或约束信息
- 价差方向定义
  - 例如峰谷差扩大 / 收窄，或日前高于实时
- 你希望展示未来多长周期
  - 日内、次日、未来 3 天

## 5. 业务规则确认

建议你确认以下问题：

- 网站面向内部使用还是外部公开
- 是否需要登录
- 是否区分管理员与普通用户
- 是否需要导出 Excel / PDF
- 是否需要移动端适配
- 是否需要部署在内网

## 6. 我建议你优先提供的最小材料

如果想最快开工，先给下面这些就足够：

1. 2 到 3 份披露数据 Excel 样例
2. 2 到 3 份政策文件样例
3. 1 份预测结果样例，或者 1 份历史电价数据
4. 你希望的网站风格参考，哪怕只是 1 到 2 个截图
