# 数据与材料准备清单

本文档用于说明系统落地和二次开发时常见的数据准备要求。实际字段、频率和数据范围可根据所在市场和业务场景调整。

## 1. 信息披露与基本面数据

建议准备以下材料：

- 披露数据样例文件。
- 每类指标的字段说明。
- 每类数据的时间粒度，例如 24 点、96 点或 15 分钟粒度。
- 每类数据的单位，例如 MW、MWh、元/MWh。
- 数据更新频率，例如每日一次或日内多次。
- 数据来源说明，例如网页导出、Excel、接口抓取或内部系统导出。

常见指标包括：

- 统调负荷。
- 地方电源出力。
- A 类电源出力。
- 新能源出力。
- 联络线功率。
- 备用和安全裕度。

## 2. 市场出清与节点电价数据

建议准备以下材料：

- 市场出清价格。
- 日前节点电价。
- 实时节点电价。
- 全省均价。
- 分类型出清电量。
- 分类型开机台数。
- 数据口径说明，例如日前、实时或预测。

如果存在多个 sheet，应说明每个 sheet 的业务含义、日期字段和时间字段。

## 3. 网架拓扑数据

网架拓扑模块通常需要：

- 节点表。
- 线路表。
- 节点名称和别名映射。
- 线路起点、终点和电压等级。
- 节点与电价数据之间的匹配规则。

如果需要阻塞原因分析，可补充：

- 实时出清断面。
- 实际断面。
- 阻塞披露信息。
- 线路检修或停运信息。

## 4. 政策文件数据

政策文件模块通常需要：

- 政策 PDF、Word 或网页文本。
- 文件标题、发布日期、发布机构和适用区域。
- 分类规则，例如区域、机构、主题和业务条线。
- 摘要输出字段，例如摘要、核心条款、影响分析和适用对象。

## 5. 预测模块数据

如果接入预测模型，通常需要：

- 历史电价。
- 历史负荷。
- 新能源出力。
- 天气数据。
- 节假日和工作日标签。
- 机组检修、约束或断面信息。
- 模型输出结果样例。

预测结果建议包含：

- 预测日期。
- 预测时点。
- 预测价格。
- 预测区间或置信度。
- 主要驱动因素。

## 6. 最小可用数据集

为了快速完成本地验证，可先准备：

1. 一到三个交易日的脱敏基本面数据。
2. 一到三个交易日的市场出清或节点电价数据。
3. 一份网架节点和线路样例。
4. 一到两份政策文件样例。
5. 一份预测结果样例，或一份历史电价数据。

具备以上材料后，可以先验证数据导入、页面展示、日期选择和图表联动，再逐步扩展真实业务数据。
